# Atlas Architecture (BENGAL SHAD)

Six fixed pillars:
1. Microservices & Cloud Infrastructure
2. Hybrid Multi-Tenant Architecture
3. Industrial Intelligence Data Fabric
4. Atlas Intelligence Engine
5. Customer-Isolated AI
6. Cyber-Physical Security

BENGAL SHAD is a cross-cutting AI governance, cyber-defense, and assurance layer,
not a seventh pillar. It sits between the data/intelligence/edge fabric and the
Atlas Trust Funnel, operating across all six pillars.

## Trust Funnel

REQUEST -> Identity -> Tenant Isolation -> Authorization -> Data Integrity ->
Cyber Risk -> SHAD AI Assurance (hallucination, poisoning, bias, drift) ->
Asset Health -> Risk Scoring -> Decision -> Safety -> Policy -> Audit Ledger ->
Edge Gateway -> Physical System.

## Closed Loop

SENSE -> UNDERSTAND -> PREDICT -> ASSURE -> RISK -> DECIDE -> SAFETY -> ACT ->
VERIFY -> AUDIT -> (learn).

## Immutable Audit

Hash-chained ledger: each event's hash includes the previous event's hash.
Modifying any event breaks the chain. Tenant-isolated.
